## 📘 30 Kunci Pembuka Pintu Rezeki

**Buku panduan Muslim mencari rezeki sesuai Al-Qur'an dan sunnah** — dari fondasi tauhid, fiqh muamalah (riba, jual beli, zakat, harta), hingga praktik harian: zikir, doa, kerja, keluarga, dan tantangan 90 hari. Ditutup dengan perpustakaan studi kasus, mitos-vs-dalil, dan 105 tanya jawab.

- **105 bab** — 30 Kunci utama + panduan khusus (muslimah, pemuda, profesi lapangan, dll.) + Tantangan 90 Hari + Tanya Jawab
- **34 lampiran (A–AH)** — bank dalil, kumpulan doa rezeki, jurnal tracker, glosarium, indeks ayat & hadits, dan lainnya
- **105/105 bab lolos audit otomatis** — struktur, dalil, anggaran kata, dan penanda kedalaman diperiksa mesin
- **Teks Arab dibaca langsung** — tanpa transliterasi Latin, sesuai preferensi pembaca Muslim
- **4 lembar pendamping per bab** — Data, LAM, Verifikasi Dalil, Serah-Terima (transparansi proses penulisan)

## 🗂️ Struktur Folder (berlaku untuk setiap buku)

```
judul-buku/
├── 01_NASKAH_MD/             ← BAHAN UTAMA: bab + lampiran (.md)
├── 02_NASKAH_WORD/           ← BAHAN UTAMA: bab + lampiran (.docx)
├── 03_PENDUKUNG_DATA/        ← lembar Data
├── 04_PENDUKUNG_LAM/         ← lembar Audit Mandiri
├── 05_PENDUKUNG_VERIFIKASI/  ← lembar Verifikasi Dalil
├── 06_PENDUKUNG_SERAH_TERIMA/← laporan Serah-Terima
└── 07_ALAT_DAN_REFERENSI/    ← TOC, bank dalil, master PDF, tool produksi
```

**Prinsipnya:** bahan utama buku (naskah + lampiran) selalu bersih — tidak pernah bercampur dengan file pendamping — dan setiap format (MD / Word) berdiri sendiri di foldernya.

## ✅ Standar Kualitas

Setiap bab wajib melewati sebelum masuk koleksi ini:

1. **Audit otomatis** — struktur blok, urutan elemen, kesesuaian judul dengan TOC, dan jumlah kata dalam toleransi (±10% bab, ±20% sub-bab)
2. **Verifikasi dalil** — teks Arab dicocokkan ke sumber resmi (API Al-Qur'an), derajat hadits ditandai terbuka, tanpa nomor yang ditebak
3. **Bebas cacat penulisan** — tanpa duplikat paragraf, tanpa bahasa proses produksi, tanpa angka karangan, angka ilustrasi wajib berlabel
4. **Lembar pendamping lengkap** — audit kualitas 46 butir per bab
